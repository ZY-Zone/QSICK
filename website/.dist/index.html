01 — Features

小内核，大能力

不做危险的模拟点击，也不套一层 Chromium。QSICK 把 QQNT 的真实收发路径接出来，保持轻量，同时把可控性交还给你。

开箱即用

start.bat 一条命令完成 uv 依赖、QQNT 运行时拉取与 WebUI 启动；mock 模式不登账号也能调试整条链路。

start.batmockWebUI

原生注入

C++ payload 以命名管道与跳板挂接 QQ 收发路径，242 个动作直达客户端能力，而不是截图识别或模拟点击。

C++ DLLHookNamed Pipe

多协议适配

协议跟着连接走：同一实例可同时挂 OneBot v11 与 Milky，事件与动作按各自连接的协议独立编解码。

OneBot v11Milky v1.3maxStore

插件系统

清单 + 权限 + 生命周期钩子，支持热重载、配置界面扩展与插件市场远程安装，故障隔离到单个插件。

manifesthookshot reload

多实例隔离

headless 与 pipe 两类实例：模板硬链接、数据目录重定向、每实例独立网络配置，多账号互不干扰。

headlesspipeisolation

可观测 WebUI

仪表盘、手写 SVG 图表、SSE 实时日志、动作测试器与消息库，把"发生了什么"变成一眼能看懂的画面。

FastAPISSESVG
02 — Architecture

一条消息的旅程

从 QQ.exe 进程内的 payload，到 Python 内核，再到你选择的协议端。三条流水线，两个分流点，职责边界清晰。

完整架构文档

QQ.exe

QSICK payload · C++
  • 命名管道 qsick.<pid>.ctl / .evt
  • 32 字节帧头 + JSON 体
  • 钩子引擎与跳板，偏移表驱动
  • 窗口隐藏、数据目录重定向
pipe · frames

qsick 内核

Python · FastAPI
  • 实例中心 / 解码 / 插件钩子
  • OneBot 事件与动作注册表
  • maxStore 先落库再分发
  • 网络配置按连接归属
http · ws · sse

协议端

HTTP · WS · SSE
  • OneBot v11 / Milky 双协议
  • 反向 WebSocket 与 HTTP 动作
  • WebUI 面板与插件市场
  • Prometheus 文本指标
事件推送QQ 宿主 → runtime → 各连接，maxStore 先于一切裁剪保存原始 payload。
动作执行连接 → 协议解码 → runtime.invoke，插件过滤、账号限制与发送锁都在这层。
原始存储maxStore 是汇不是通道：没有端口，只把完整历史留在实例自己的库里。
帧 32 B header + JSON body 管道 ctl / evt 动作 242 registered 协议 onebotv11 · milky · maxStore
03 — Quick Start

三步，让 QQ 开口说话

Windows 双击即用；想先评估效果，可以走 mock 模式，不连接任何真实账号。

快速开始文档
01

安装依赖

首次运行 start.bat 会用 uv 安装 Python 依赖，并检查 node 与 Python 环境。

02

获取 QQNT 运行时

脚本联网拉取 QQNT-9.9.33-52230；网络不稳时可先双击 获取QQnt.bat 预下载。

03

打开 WebUI

浏览器访问 127.0.0.1:5754：仪表盘、日志、动作测试器与实例管理都在这里。

只想看看效果？qsick --mock 用 Mock 传输跑通事件与动作链路，不需要真实账号，也不会连接 QQ 服务器。
