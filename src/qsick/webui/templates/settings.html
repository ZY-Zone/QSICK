光标包格式

一个 ZIP，一份 cursor.json，若干图片。name 与 description 会显示在卡片上，description 不超过 12 字。没定义的状态沿用初始箭头。

cursors 的键是状态名，值是包内图片路径；hotspots 是点击生效的坐标， 省略即 [0, 0]。图片支持 PNG / SVG / WebP / ICO / GIF。 只需要这 {{ cursor_types|length }} 种——其它状态界面里不会出现。
